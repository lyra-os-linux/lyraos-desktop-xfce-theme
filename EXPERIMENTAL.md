# Escopo experimental

Este projeto preparará a integração visual de XFCE, Xfwm e LightDM sem alterar
o pacote GNOME oficial. O repositório ainda contém a base histórica usada na
derivação e não deve ser empacotado ou publicado como tema XFCE até que os
assets e os testes específicos do flavor sejam implementados.

Os wallpapers comuns pertencem ao pacote independente `lyra-os-wallpapers`.
